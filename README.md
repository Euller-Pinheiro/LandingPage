# Landing page pessoal

Minha primeira página de apresentação como desenvolvedor: cabeçalho com foto e menu, seção de apresentação e contato.

Projeto de estudo de 2023 (HTML e CSS), mantido aqui como registro da minha evolução.

## Como rodar

Abra o `index.html` no navegador.

## O que pratiquei

- Semântica HTML (header, nav, section)
- CSS com nomenclatura de classes por bloco
- Publicação de uma página estática
